# Long-term support policy

Mythos OS v1 is supported for 24 months from the v1.0.0 release date.

- Full bug-fix support: 12 months.
- Security and critical production fixes: 24 months.
- Critical security advisories receive prioritized PATCH releases.
- Supported PHP, Laravel and dependency versions follow their upstream security support windows.

Stable Core contracts remain source-compatible throughout v1. Deprecations receive at least one MINOR release of notice and are removed only in a MAJOR release.

Security fixes may tighten validation, headers, unsafe URL handling or dependency constraints without being considered business behavior changes.
